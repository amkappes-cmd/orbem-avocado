# Genus Echo for avocados

Marketing landing page for Orbem's avocado inspection application.

## Design

Uses the typography, color palette, spacing, buttons, navigation, split layouts and light/dark sections of `amkappes-cmd/orbem-watermelon`. Avocado-specific additions are at the end of `styles.css`.

## Content and assets

The page adapts the supplied Orbem avocado introduction and avocado imagery. Example grades are illustrative, with customer criteria configured and validated during an assessment. It does not publish the original presentation, private customer notes, or competitive research.

All main calls to action use the booking destination already used on the watermelon page.

## Preview

Serve this directory with any static web server. There are no build dependencies.

## GitHub Pages

Publish the root directory of the `main` branch. `.nojekyll` keeps this a plain static site.
